Política de Privacidade

Super Conversor Multifuncional

Última atualização: 28 de agosto de 2026

1. Introdução

Esta Política de Privacidade descreve como o aplicativo Super Conversor Multifuncional, desenvolvido pela Free Game Plant (FGP), trata as informações dos usuários.

A privacidade dos usuários é importante para nós. O aplicativo foi desenvolvido para realizar conversões e cálculos diretamente no dispositivo do usuário.

2. Coleta de dados

O Super Conversor Multifuncional não coleta, armazena ou compartilha informações pessoais dos usuários.

O aplicativo não solicita cadastro, nome, endereço, número de telefone, e-mail ou outras informações pessoais para funcionar.

3. Armazenamento de informações

As informações inseridas pelo usuário para realizar conversões são processadas localmente no dispositivo, quando aplicável.

Não mantemos um banco de dados com informações pessoais dos usuários.

4. Compartilhamento de dados

Como o aplicativo não coleta informações pessoais, não compartilhamos dados pessoais dos usuários com terceiros.

5. Serviços de terceiros

O aplicativo pode utilizar serviços fornecidos pelo sistema Android ou pela plataforma Google Play para distribuição e funcionamento do aplicativo.

Esses serviços podem possuir suas próprias políticas de privacidade. Recomendamos consultar as políticas correspondentes do Google quando necessário.

6. Segurança

Embora nenhum sistema possa garantir segurança absoluta, adotamos medidas razoáveis para manter o aplicativo funcionando de forma segura e proteger as informações processadas localmente.

7. Privacidade de crianças

O aplicativo não foi desenvolvido para coletar informações pessoais de crianças ou adolescentes e não solicita esse tipo de informação.

8. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada eventualmente para refletir mudanças no aplicativo, nos requisitos legais ou nas práticas de privacidade.

Quando houver alterações relevantes, a data de atualização apresentada nesta página será modificada.

9. Contato

Caso tenha dúvidas sobre esta Política de Privacidade ou sobre o tratamento de dados relacionado ao aplicativo, entre em contato com a equipe da Free Game Plant (FGP).
